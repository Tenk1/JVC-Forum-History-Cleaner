Trouver les IDs JVC

Tout se lit directement dans les URLs.

Forum + topic https://www.jeuxvideo.com/forums/42-12345-98765432-1-0-1-0-exemple.htm

12345 = ID du forum
98765432 = ID du topic

Message https://www.jeuxvideo.com/forums/message/1234567890

1234567890 = ID du message.

…/un-topic.htm#post_1234567890

L’ID après #post_ est également l’ID du message.

Astuce : pour « Messages à garder » et « Topics à garder », tu peux coller directement l’URL complète. L’extension extrait l’ID toute seule.
