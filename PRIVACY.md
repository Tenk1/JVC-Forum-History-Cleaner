# Politique de confidentialité — JVC Forum History Cleaner

JVC Forum History Cleaner ne collecte, ne vend et ne transmet aucune donnée à son développeur ni à un service tiers.

L’extension fonctionne localement dans Firefox. Elle communique uniquement avec `www.jeuxvideo.com` afin de :

- vérifier la session Jeuxvideo.com actuellement connectée ;
- lire l’historique forum du compte connecté ;
- récupérer les informations nécessaires au filtrage et à la prévisualisation ;
- envoyer, à la demande de l’utilisateur, les requêtes de suppression de ses propres messages.

Le popup peut être ouvert depuis n’importe quel site. Pour conserver le contexte d’authentification Jeuxvideo.com, l’extension peut créer une page Jeuxvideo.com inactive dédiée au traitement. Elle n’analyse pas le contenu de l’onglet non-JVC que l’utilisateur consulte.

Les réglages de l’extension sont enregistrés localement avec `browser.storage.local` dans le profil Firefox. Le journal peut être exporté uniquement lorsque l’utilisateur clique sur le bouton d’export ; le fichier est alors créé localement sur l’appareil.

L’extension ne contient aucune télémétrie, publicité, analytics, pixel de suivi ou code distant.

Cette extension est un projet non officiel et n’est ni affiliée ni approuvée par Jeuxvideo.com ou Webedia.
